# Чернетка висновку

**Ефект попереднього навчання (Δpre).** Напрям: frozen вищий за scratch
(F̄_frozen = 0.8836 проти 0.6000). Величина: +28.35 п. macro-F1.
Співвідношення з розкидом: |Δpre| = 0.2835 > R = 0.0097
(R_frozen = 0.0051, R_unfreeze = 0.0097) → ефект вартий перевірки, але не доведений.

**Ефект розморожування (Δunf).** Напрям: unfreeze вищий за frozen
(F̄_unfreeze = 0.8887 проти 0.8836). Величина: +0.52 п. macro-F1.
Співвідношення з розкидом: |Δunf| = 0.0052 ≤ R = 0.0097 → не відрізняється від розкиду: результату немає.

Повний виграш трансферу відносно навчання з нуля: Δpre + Δunf = +28.87 п. macro-F1.
Обидва ефекти виміряно за конкретного бюджету 304 кроки оптимізатора: з довшим навчанням scratch міг би скоротити відставання.
