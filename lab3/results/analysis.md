## Розклад ефектів (п. 4)

| Величина | Значення |
|---|---|
| F_scratch,1 | 0.6000 |
| F̄_frozen | 0.8836 |
| R_frozen | 0.0051 |
| F̄_unfreeze | 0.8887 |
| R_unfreeze | 0.0097 |
| R = max(R_frozen, R_unfreeze) | 0.0097 |
| Δpre = F̄_frozen − F_scratch,1 | +0.2835 |
| Δunf = F̄_unfreeze − F̄_frozen | +0.0052 |
| Δpre + Δunf = F̄_unfreeze − F_scratch,1 | +0.2887 |
| |Δpre| ≤ R ? | ні |
| |Δunf| ≤ R ? | так |

Правило: окремо для Δpre і Δunf - якщо |Δ| ≤ R, різниця не відрізняється від розкиду (результату немає); якщо |Δ| > R,
ефект вартий перевірки, але не доведений.

- **Δpre = +0.2835**: ефект вартий перевірки, але не доведений.
- **Δunf = +0.0052**: не відрізняється від розкиду: результату немає.

Допоміжні числа для пояснень:

- Крива scratch (зерно 1), macro-F1 за епохами: 0.377, 0.390, 0.524, 0.529, 0.328, 0.535, 0.439, 0.600.
